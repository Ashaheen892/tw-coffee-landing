# tw-coffee-landing

صفحتا هبوط لمحمصة في سلة، على مثال لوحة القهوة: غلاف، مناشئ، درجة تحميص، حاسبة تحضير، باقات، عدّة، آراء، ثم طلب الكيس. سلة تطلب قالبين على الأقل، لذلك الصفحة الكاملة اسمها القهوة، والمختصرة اسمها الكيس.

التاجر يختار القالب من قنوات البيع ثم صفحات الهبوط، ويعدّل النصوص من لوحة التحكم. في صفحة منتج يفتح زر السلة الشراء السريع. في صفحة العروض يتبع رابط الزر.

اختيار المنشأ ودرجة التحميص يحدّثان إجمالي الكيس في قسم الطلب.

## القهوة — `templates/qahwa.json`

1. رأس الصفحة
2. غلاف التحميص
3. قائمة المناشئ
4. مقياس التحميص
5. حاسبة التحضير
6. جدول الباقات
7. عدّة التحضير
8. أصوات الزبائن
9. طلب الكيس
10. فوتر الصفحة

رأس الصفحة فيه زر تبديل بين الفاتح والداكن. الصفحة تفتح داكنة، بلون المحمصة. شريط «اطلب» يثبت أسفل الشاشة ويختفي عندما يصل الزائر إلى قسم الطلب.

## الكيس — `templates/kis.json`

صفحة أقصر للطلب المباشر: رأس الصفحة، الغلاف، المناشئ، طلب الكيس، ثم فوتر الصفحة.

## التطوير

```bash
pnpm install
pnpm dev
pnpm build
pnpm audit:salla
```

المعاينة المحلية: `http://localhost:5173/node_modules/.salla-temp/index.html`
